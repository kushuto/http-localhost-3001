# 🔧 Аренда и прокат электроинструментов

**Веб-сайт для индивидуального предпринимателя И.Н. Гиш**  
(а. Тахтамукай)

Дипломная работа на тему:  
«Проектирование и разработка веб-сайта (на примере индивидуального предпринимателя И.Н. Гиш, а. Тахтамукай)»


## 📖 О проекте

Данный веб-сайт разработан для автоматизации деятельности ИП И.Н. Гиш в сфере аренды и проката электроинструментов. 

Система предоставляет пользователям возможность:
- 🔍 **Просматривать каталог** доступных электроинструментов
- 🛒 **Добавлять товары в корзину** и оформлять заказ
- 🧮 **Рассчитывать стоимость аренды** в зависимости от количества дней
- 👤 **Создавать личный профиль** с возможностью авторизации
- 👨‍💼 **Ознакомиться с информацией** об организации, услугах и сотрудниках

Для администратора предусмотрен отдельный интерфейс:
- Вход по специальным логину и паролю
- Управление каталогом товаров: добавление, редактирование, удаление
- Изменение названия, цены и статуса наличия товара


## 🛠 Стек технологий

| Компонент | Технология |
|-----------|------------|
| **Серверная часть** | Node.js |
| **Клиентская часть** | HTML, CSS, JavaScript, Vue.js |
| **База данных** | SQLite Browser |
| **Среда разработки** | Visual Studio Code |
| **Запуск** | Команда `npm start` |


## 🚀 Запуск проекта

Проект работает локально. Для запуска выполните следующие шаги:

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/kushuto/http-localhost-3001.git

2. Установите зависимости
bash
npm install

3. Запустите приложение
bash
npm start

4. Откройте в браузере
Перейдите по адресу:
http://localhost:3001

🔑 Тестовый доступ
Для входа в систему как администратор:
Логин	admin
Пароль	admin123

📊 База данных
Проект использует SQLite Browser для хранения:

Логинов и паролей пользователей
Данных о товарах (инструментах)
Информации о заказах
База данных автоматически создаётся при первом запуске приложения.
