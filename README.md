# 🔧 Аренда и прокат электроинструментов

**Веб-приложение для ИП по аренде электроинструментов** — дипломный проект.

Система позволяет клиентам арендовать инструменты онлайн, а администратору — вносить изменения товаров.

## 🚀 Как запустить локально

### 1. Установи зависимости
```bash
npm install

Настрой базу данных
npm run db:init   # или команда, которую ты используешь для инициализации БД

Запусти сервер
npm start

Сайт будет доступен по адресу:
http://localhost:3001
